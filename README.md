# 影之刃零 · 任务助手

**版本 1.3.1（本地修复版）** · 64 位 Windows · Steam 版《影之刃零》

读取本机存档，按需查看当前地图相关任务、推进条件、可能错过的奖励和成就。攻略可以随时查阅，探索顺序由玩家决定。

## 下载与使用

1. 可直接运行助手浏览全部任务与节点检查。读取个人进度时，需安装 Steam 版《影之刃零》，并在游戏内至少保存一次。
2. 本地修复版的可执行文件位于 `release/PBZ-Quest-Guard-1.3.1-native-win-x64.exe`，双击运行。GitHub 已发布版本见[发行页](https://github.com/DeianHsu/pbz-assistant/releases)。
3. 助手会自动打开游戏「继续游戏」对应的槽位，进入「任务助手 → 当前进度 → 当前可做」，按当前活动目标显示本地图可推进的事项。列表直接列出地图、处理阶段、下一步和前置条件。跨地图前置通过顶部「查看提醒」单独查阅，并按地图分组。查看其他进度时，在窗口顶部切换账号和槽位。
4. 要查看其他位置的存档或备份，点击 **选择存档文件**，打开对应的 `.sav` 文件，再切换其中的槽位。点击 **自动查找** 可返回本机账号存档。
5. 游戏再次保存后，点击 **重新读取存档** 或按 **F5** 更新进度。本次运行中，手动选择后会继续读取该文件；用窗口底部的保存时间和文件路径确认当前存档。
6. 「任务助手」提供 **当前进度** 和 **全部任务** 两个视图。同一任务只列一行，底部保留摘要；点击 **查看完整攻略** 打开可最大化的独立窗口。选择地图或查阅其他任务只改变显示范围，存档进度按所选槽位读取。
7. 在「当前进度」选择检查节点，分别查看任务状态与本节点条件。点击 **查看关联任务** 查阅完整流程；在任务列表点击 **关联检查** 可反向查看相关节点。节点检查只展示具体条件，保持任务整体进度独立。
8. 顶部提醒默认收起，支持展开或集中查看。任务的风险、卡点与奖励合并展示，可 **忽略所示提醒**，在「已忽略提醒」恢复。点击 **返回当前进度** 清除手动选定的地图和节点。

助手使用 Windows 的 .NET Framework 4.x 系统组件。单个 EXE 即可离线运行，对本机游戏资源和存档只做读取。

## 按用途查找

| 页面 | 怎么用 |
| --- | --- |
| **任务助手** | 「当前进度」默认显示当前地图可做事项；「前置未满足」列出卡点和后续地区，「存档证据不足」保留缺少字段或无法定位的活动目标。顶部「查看提醒」单独展示跨地图事项，按地图与节点分组。「全部任务」可查全部流程、已完成任务、失败原因和资源留档。两个视图均显示地图与阶段。无存档时默认进入全部任务。 |
| **地图收集** | 选地区和类别，按点位核对铃铛、装备、碎片、记忆之花和挑战。选中条目可查附近铃铛和已核对的路线。回访时切换「全部点位」查看完整清单。 |
| **全收集品** | 可按名称搜索装备、书籍、花瓣、珍宝和收集点，也可按地区、类别和状态筛选。想补铸魂时选择「已持有待铸魂」，点开装备查看材料与路线。钱和普通升级材料不列入目录与收集统计；铸魂材料和相关合成部件保留。 |
| **成就** | 「前置已满足」适合按当前槽位找可以着手的成就。点开条目可查招式、等级要求和逐项进度。也可切换「暂不可取」「已解锁」和「全部成就」。 |
| **小张珍宝** | 按地区查看缺少哪些珍宝、哪一组可以交付，以及已经交付的地区。 |
| **资料来源** | 查看任务和收集路线所用的攻略。部分条目的详情也附有对应链接。 |

## 进度与状态

- **任务。** 「可接取」根据当前周目的到访、铃铛和已知剧情条件判断。地点或条件待核实时，查看条目详情并与游戏日志对照。
- **条件与卡点。** 当前地图按任务活动目标定位；已完成的历史步骤、后续地区目标和未满足条件的目标分别查阅。同一收集任务在当前列表只列本地图可处理的点位。已知缺少的钥匙、能力或首领前置直接显示具体原因；真正缺少存档证据的内容归入「存档证据不足」。当前所在地或本周目到访可以证明已进入后街，武轩及其他门锁仍分别判断。已有失败证据时保留原因及补救说明。
- **风险提醒。** 当前地图及仍开放检查的阶段事项汇总显示，包含跨地图前置；默认只占一行，展开后预览前三项。「当前提醒」按任务合并显示，每项具体风险和奖励可在摘要核对。提醒依据最近读取的存档，精确截止条件尚未核实的条目保留原说明。忽略只影响本次运行中的提醒展示，按存档文件、槽位和周目区分；任务事实和完整攻略仍可查阅。
- **奖励核对。** 对明确标注了领取条件的任务奖励单独核对。已满足领取条件却缺少本周目获取记录时提示核对；物品字段不足时显示「领取待核实」。任务所需物品、普通珍宝收集与结算奖励分别处理。小翠的战后奖励在对应首领战结束后再提示。
- **检查节点。** 在「当前进度」中选择节点，或通过「关联检查」查看。节点总览显示推进情况和必需检查数量，同一任务的条件合并到一行。任务整体状态与本节点条件分别显示，例如「归途进行中」与「告知密道已通的条件已满足」可以同时成立。可选条件不计入节点必需检查的分母，节点已越过时仍按存档证据判断。
- **文字攻略。** 独立详情窗口提供「当前情况」「完整流程」「判断依据与来源」。完整流程按连续的同地图步骤分块，返回此前地图时另列「回访」区块。各步标题后显示状态：绿色「已完成」、黄色「正在进行」、灰色「未完成」；「待核实」和失败状态单独标明。左侧地图目录可展开并跳转到步骤，正文支持搜索、字号调整和本次运行中的阅读位置保留。
- **逐步状态。** 任务分支、事件、物品和目标记录用于判定步骤。缺少对应证据时显示「待核实」；任务结算与奖励领取分别核对。失败原因无法从存档确定时，明确显示原因未知。
- **未读取存档。** 「任务助手」默认显示「全部任务」，可按地图筛选、搜索并打开完整攻略；在「当前进度」也可选择全部检查节点。「资料来源」可直接查看。个人进度和每一步均标为「未读取存档」，读取成功后同步实际状态。
- **收集。** 地图页按点位核对，全收集品按物品归类。装备按基础形态统计，铸魂材料和合成部件分开。催心琵琶通过「幻术琵琶」任务修复。
- **路线。** 「已知前置满足」表示存档里有对应的前置记录。「本区流程收集」表示可沿详情中的区域路线寻找。「暂不可取」会列出缺少的条件，「解锁待核实」需要在游戏里确认。
- **成就。** 解锁状态按本机账号读取，前置条件和可读取的进度按所选槽位判断。

## 常见问题

- **找不到存档。** 确认游戏通过 Steam 安装，在游戏内保存一次后按 F5；存档位于其他位置时，可点击「选择存档文件」手动打开。手动读取仍需本机安装受支持的游戏版本，以读取解密和分析所需的游戏资源。
- **只有备份存档，未安装游戏。** 可以直接查看全部任务、节点检查与文字攻略。读取备份中的个人进度仍需本机游戏程序提供解密信息和任务、地图、物品资源；手动选档读取失败后会弹出具体原因。
- **进度和游戏不同。** 检查窗口顶部的账号和槽位，以及底部保存时间。切换到旧槽位后，任务和收集进度会按该槽位显示，成就解锁仍读取账号记录。
- **提示版本未经验证。** 本版支持 Steam 游戏构建 **26266538、26367565**。可在提示中核对本机的构建编号。
- **下载后出现安全提示。** 发布的 EXE 尚未签名。如被安全软件隔离，反馈时请附检测名称和文件路径。
